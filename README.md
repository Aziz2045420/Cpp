# C++ Exam Simulations

These exercises are built only from the topics that appear in your professor's files:

- `hello.cpp`
- `intin.cpp`
- `intout.cpp`
- `strin.cpp`
- `sum.cpp`
- `gcd.cpp`
- `call.cpp`
- `strings.cpp`
- `replace.cpp`
- `vectors.cpp`

Use them like mini exam sessions. Try to solve each file without looking at the original examples first.

## Rules for practice

- Stay inside the covered material: `iostream`, `string`, `vector`, `algorithm`, loops, `if`, functions, references.
- Do not use classes, pointers, recursion, maps, files, or advanced libraries.
- If a task says "read a line", use `getline`.
- If a task says "modify the original string", pass it by reference.

## How to use

1. Open one file.
2. Read the task comment at the top.
3. Fill in the `TODO` parts.
4. Compile and run it.

Example compile command:

```powershell
g++ -std=c++20 .\01_welcome_sum.cpp -o .\01_welcome_sum
```
